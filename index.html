Endpoint Utama

GET /api/sekolah

Mengembalikan daftar sekolah dalam format JSON. Gunakan parameter di bawah untuk pencarian dan paginasi.

Parameter URL (Query)

keyword

Cari berdasarkan NPSN atau nama sekolah.

?keyword=surabaya

limit

Data per halaman (default 20, maks. 50).

?limit=50

offset

Paginasi — mulai dari baris ke-n.

?offset=100
Parameter Deskripsi Contoh
keyword Mencari berdasarkan NPSN atau penggalan nama sekolah. ?keyword=60723552
limit Jumlah data per halaman (default: 20, maksimal: 50). ?limit=50
offset Titik mulai paginasi (default: 0). ?offset=20

Metadata respons

  • total_data_tersedia — jumlah hasil di database
  • waktu_update_data_terakhir — update terakhir (WIB)
