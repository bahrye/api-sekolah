Endpoint Utama

GET /api/sekolah

Mengembalikan daftar sekolah dalam format JSON. Gunakan parameter di bawah untuk pencarian dan paginasi yang spesifik.

Parameter Query

Parameter Deskripsi Contoh
keyword Mencari berdasarkan NPSN spesifik.
?keyword=60723552
limit Jumlah data per halaman (default 20, maks 50).
?limit=50
offset Titik mulai paginasi (default 0).
?offset=20
